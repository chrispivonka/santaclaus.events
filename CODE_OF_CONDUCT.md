# Code of conduct

This is a small, family-friendly project, and everyone who takes part in it (in issues, pull requests, reviews and discussions) is expected to keep it that way.

- Be kind and patient, and assume good intent.
- Keep it suitable for all ages: the site is for children and their families.
- Give feedback on the work, never on the person.
- No harassment, insults, discriminatory jokes, sexual content, or sharing anyone's private information.

The maintainer may edit or remove comments, close issues or pull requests, and block anyone who doesn't follow this. To report a problem privately, use the contact details on [@chrispivonka's GitHub profile](https://github.com/chrispivonka). Reports are kept confidential.

This code is based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1, which covers anything not spelled out here.
